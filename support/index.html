Common questions

Nothing happens when I press play

Chimereader reads the text layer of a PDF. Scanned documents that are images of pages have no text layer, so there is nothing to read. Opening the file in Preview and trying to select a word is a quick way to tell: if you cannot select it, Chimereader cannot read it either.

It reads the header or page number aloud

Layout detection identifies and skips those. If the optional layout model has not been downloaded, the app falls back to reading the page as plain text, which includes them. Check Settings for the model status.

The voice sounds robotic

Chimereader uses the voice built into your device. You can change it in your system settings — on macOS under System Settings → Accessibility → Spoken Content → System Voice, where higher-quality voices can be downloaded free from Apple.

The highlight is in the wrong place

Alignment maps spoken words onto the positions extracted from the PDF. Unusual layouts — heavy multi-column text, tables, or documents produced by uncommon tools — can misplace it. Sending us the PDF, if you are able to share it, is the most useful thing you can do.

Can I use it offline?

Yes. Reading a document needs no network.

Does it work on my iPhone and iPad too?

Yes. One purchase covers Mac, iPad and iPhone.

Reporting a problem

Please include your device and OS version, what you expected, and what happened. If it concerns a specific document, telling us roughly how it was produced — exported from Word, scanned, generated by LaTeX — usually narrows it down quickly.
